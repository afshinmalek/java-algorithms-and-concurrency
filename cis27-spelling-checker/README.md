# Spelling Checker

HashSet dictionary lookup with edit-based correction suggestions (insert, delete, swap, replace).

## Run

```bash
javac SpellingChecker.java
java SpellingChecker
# Requires a words.txt dictionary file in this folder (not included).
```

Compile each project folder on its own. Some projects define classes with the same names (for example, `Edge` and `G50` appear in both the Shortest Path and MST projects), so do not compile the whole repo together.
