# Supplier-Consumer — Threads and Wait/Notify

Ten suppliers and ten consumers coordinated through a MeetingRoom using synchronized wait/notify, with timestamped logging.

## Run

```bash
javac *.java
java SupplierConsumerSimulation
```

Compile each project folder on its own. Some projects define classes with the same names (for example, `Edge` and `G50` appear in both the Shortest Path and MST projects), so do not compile the whole repo together.
