# Maze — Union-Find

Union-find maze generation: cells are joined by removing walls until the maze is fully connected. Library code, no main method; a sample maze is shown in the source comments.

## Run

```bash
javac Maze.java
```

Compile each project folder on its own. Some projects define classes with the same names (for example, `Edge` and `G50` appear in both the Shortest Path and MST projects), so do not compile the whole repo together.
